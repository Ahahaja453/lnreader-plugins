Плагин LN Reader: Redaktorskaya — Поднося вино
Целевая версия приложения: LN Reader 2.1.4

ВАЖНО
Это исходный прототип плагина, а не готовый устанавливаемый репозиторий.
Он ещё не собран и не проверен внутри Android-приложения. Перед использованием
нужно проверить селекторы страниц сайта и совместимость импортов с текущей
сборкой LNReader Plugins. Если сайт изменит разметку, парсер может потребовать правок.

Файл redaktorskayaWine.ts предназначен для размещения в каталоге:
plugins/russian/redaktorskayaWine.ts
в проекте LNReader Plugins.

Сайт:
https://read.redaktorskaya.date/contents/wine/

Плагин извлекает ссылки на главы из оглавления и пытается получить содержимое
страницы главы. Он не обходит платный доступ и не скачивает закрытый EPUB.
Доступны только те главы, которые сам сайт отдаёт без дополнительной авторизации.

Для полноценной установки необходима сборка через официальный шаблон
репозитория LNReader Plugins и проверка командой check:plugin.
